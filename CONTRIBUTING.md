# Contributing

Start with [AGENTS.md](AGENTS.md), the [roadmap](ROADMAP.md), and the [ranked work](docs/GAPS.md). This repository currently holds the plan, not a runnable browser.

Choose a task with clear dependencies and a definition of done. Keep changes narrow enough to review, describe the user-visible result, and attach evidence that supports completion. For docs, run `python3 tools/check_docs.py` and review consistency. Future application work needs checks appropriate to its data, security, and interaction boundaries.

Behavioral research needs source/date/confidence and an original summary. Do not attach raw user exports, private URLs, personal screenshots, or vendor assets to public issues or pull requests. Use synthetic examples. Report suspected vulnerabilities privately once an actively monitored reporting channel is established; do not disclose exploit details in public issues.

Original contributions use the repository's MIT license. Third-party components retain their own licenses; document them before inclusion. No contributor agreement or external account is required to read or build this planning repository.

# myArc, forever yours.

An open-source browser bringing back Arc, with no account required and optional AI.

[Download](https://myarc.dev/download/)
[v2026.11.26](https://github.com/bitbonsai/myarc/releases)

## How you browse is part of how you work. It should outlast the company behind your browser.

[Arc is being sunsetted](https://arc.net/), and its code was never open, so nobody can keep it going. **myArc is open source**, so anyone can.

## What we hold to

- ### Yours to keep

  Your workspace stays on your computer, in local JSON files you own. Export your pins and Favorites as standard Netscape HTML any time.
- ### Keep what worked

  If you used Arc, you already know myArc. One-click import brings over your Profiles, Spaces, Favorites, folders and pinned tabs.
- ### AI by choice

  AI is off until you turn it on. Then you pick: a local model, your own API key, or a hosted option, and you decide what it can see.
- ### Built in the open

  The code is GPL-3.0, and the plans and decisions are public too. If I stop, anyone can pick it up where I left off.

## Where it stands

[See it full size](https://myarc.dev/product-window-light.webp)[See it full size](https://myarc.dev/product-window-dark.webp)

- ### Works now

  Spaces across isolated Profiles, Favorites, pinned tabs and folders, Split View, Peek, Little Arc, one-click Arc import, built-in ad blocking, Chromium extensions, and opt-in CLI and MCP agent control.
- ### Next, for beta

  Nested folders, multi-pane Split View, workspace export, Boosts, and durability, accessibility and memory gates.
- ### Later

  Windows and Linux builds, plus optional AI with a local model, your own API key, or a hosted option.

# Keyboard shortcuts

The shortcuts that work in myArc today, and the Arc shortcuts that are still missing.

These shortcuts work in the current nightly. Standard Chromium shortcuts, such as Cmd\+W to close a tab and Cmd\+R to reload, work as they do in Chrome.

| Shortcut | What it does | Compared with Arc |
| --- | --- | --- |
| Cmd\+T | Opens the command bar for a new tab | Same |
| Cmd\+L | Opens the command bar on the current address | Same |
| Cmd\+S | Hides or shows the sidebar | Same |
| Cmd\+D | Pins the current tab to its Space, or unpins it if it's pinned. A Favorite stays: remove it from its right-click menu | Same |
| Ctrl\+1 to Ctrl\+8 | Switches to the first to eighth Space of the current Profile. Ctrl\+9 switches to the last | Same |
| Cmd\+Option\+Left, Cmd\+Option\+Right | Switches to the previous or next Space | Same |
| Cmd\+Option\+Up, Cmd\+Option\+Down | Opens the previous or next row of the sidebar | Same |
| Cmd\+Shift\+C | Copies the current address and shows a Copied Current URL message | Same |
| Cmd\+Shift\+T | Reopens the last closed tab, or the [Peek](https://myarc.dev/docs/peek/) you just closed | Same |
| Cmd\+Shift\+N | Opens a private window | Same |
| Ctrl\+Cmd\+N | Opens a blank window | Same |
| Cmd\+, | Opens Settings | Same |
| Cmd\+Q | Quits without asking. Settings \> General has a switch to turn on a warning | Same key |
| Ctrl\+Tab | Switches to your last tab. Hold Ctrl and press Tab again to go further back through the five most recent, and add Shift to go the other way | Same |
| Ctrl\+Shift\+\= | Opens a Split View next to the current tab | Same |
| Ctrl\+Shift\+- | Separates a Split View and keeps both tabs | Arc closes the current pane instead |
| Ctrl\+Shift\+1, Ctrl\+Shift\+2 | Moves focus between the two panes of a Split View | Same |
| Cmd\+O | Turns a Peek card into a tab, or moves a Little Arc page into your current Space | Same |
| Cmd\+Option\+N | Opens Little Arc, a small window for a quick page, from any app | Same |

Cmd\+1 to Cmd\+8 open the first eight rows of the sidebar, Favorites first, and Cmd\+9 opens the last. In a Little Arc, Cmd\+Option\+O opens a menu of your Spaces under the Open in button. Pick one to move the page there.

The command bar is the box for addresses and searches. Inside it, the arrow keys move through suggestions, Enter opens the selected one and Escape closes the bar. Type an action, such as pin, archive, split or a Space's name, to run it, or type / to list the actions.

Press Tab in the empty command bar to switch to Actions mode, which lists only actions, as Arc does. Press Tab again, or Backspace in the empty field, to go back.

Cmd\+Shift\+C opens the element inspector in Chrome. myArc follows Arc and copies the address instead.

Ctrl\+Option\+Cmd\+A is a hidden extra that plays the welcome's arrival again, sound included, without restarting the tour. Esc or a click closes it. To take the whole tour again, open Settings, go to Advanced and click Replay welcome tour.

You can't change shortcuts yet. The Shortcuts tab in Settings is greyed out until it's built.

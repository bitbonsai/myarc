# Docs

How to move from Arc to myArc: install the nightly, import your Spaces, learn the shortcuts, find your data, script the browser and work around known limitations.

## Getting started

- [Install myArc](https://myarc.dev/docs/install/)

  What your Mac needs, how to get past the first-launch warning, and how to move to a newer nightly.
- [Import from Arc](https://myarc.dev/docs/import-from-arc/)

  Export your Spaces from Arc, preview what myArc will add, and import them as pinned tabs. Importing the same file twice adds nothing.

## Your workspace

- [Spaces and Profiles](https://myarc.dev/docs/spaces-and-profiles/)

  How Spaces, Profiles, pinned tabs, Favorites and temporary tabs fit together in the myArc sidebar.
- [Keyboard shortcuts](https://myarc.dev/docs/shortcuts/)

  The shortcuts that work in myArc today, and the Arc shortcuts that are still missing.
- [Your data](https://myarc.dev/docs/your-data/)

  Where myArc keeps your workspace on disk, how to back it up, and what it sends over the network. There is no account.

## Control

- [CLI and MCP](https://myarc.dev/docs/cli-and-mcp/)

  Drive myArc from a script or an AI agent with the bundled myarc command and its MCP server. It's off by default, and tab commands reach only the Agent Space.

## Help

- [Known limitations](https://myarc.dev/docs/known-limitations/)

  What the pre-alpha nightly can't do yet, and what to do after a crash or when something breaks.

## Contributing

Plans, the alpha checklist and contributor docs live in the [myArc repository](https://github.com/bitbonsai/myarc) on GitHub.

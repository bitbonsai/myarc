# Ad blocking

How myArc blocks ads and trackers, and how to turn blocking off or on for one site.

myArc blocks ads and trackers on every site from the first page you open. It does this with uBlock Origin Lite, which comes with myArc and is installed in each Profile. It needs no account and downloads nothing when it starts.

## Turning blocking off for one site

If a site breaks or asks you to allow ads, open its site info: click the "i" at the left of the address field, or choose Window \> Ad Blocking for This Site…. Turn off Block ads on this site. The page reloads with nothing blocked. Turn the switch back on to block ads there again.

The switch only changes the site you're on. Other sites keep blocking, and so do your other Profiles: each Profile keeps its own list of sites.

## More blocker settings

Under the switch, More blocker settings… opens uBlock Origin Lite's own panel. It has four filtering modes for the site: no filtering, basic, optimal and complete. Optimal is the default. The switch and the panel change the same setting, so off in one shows as no filtering in the other, and on puts the site back at your default mode.

To remove the blocker from a Profile, go to the Extensions page and remove uBlock Origin Lite. myArc doesn't put it back.

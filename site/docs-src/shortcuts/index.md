These shortcuts work in the current nightly. Standard Chromium shortcuts, such as Cmd+W to close a tab and Cmd+R to reload, work as they do in Chrome.

| Shortcut | What it does | Compared with Arc |
| --- | --- | --- |
| Cmd+T | Opens the command bar for a new tab | Same |
| Cmd+L | Opens the command bar on the current address | Same |
| Cmd+S | Hides or shows the sidebar | Same |
| Cmd+Shift+C | Copies the current address and shows a Copied Current URL message | Same |
| Cmd+Shift+T | Reopens the last closed tab | Same |
| Cmd+Shift+N | Opens a private window | Same |
| Ctrl+Cmd+N | Opens a blank window | Same |
| Cmd+, | Opens Settings | Same |
| Cmd+Q | Quits without asking. Settings > General has a switch to turn on a warning | Same key |

The command bar is the box for addresses and searches. Inside it, the arrow keys move through suggestions, Enter opens the selected one and Escape closes the bar.

Cmd+Shift+C opens the element inspector in Chrome. myArc follows Arc and copies the address instead.

## Arc shortcuts that don't work yet

These belong to features myArc doesn't have yet.

| Shortcut | What it does in Arc |
| --- | --- |
| Cmd+Option+N | Opens Little Arc, a small window for a quick page |
| Ctrl+Shift+1, Ctrl+Shift+2 | Moves focus between the panes of a Split View |
| Cmd+O | Turns a Peek preview into a tab |

You can't change shortcuts yet. The Shortcuts tab in Settings is greyed out until it's built.

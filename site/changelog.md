# Changelog

One entry per alpha release, newest first, written for people using myArc. The homepage's Recent updates dialog shows them, and the build stops when the version in `release.json` has no entry here.

## v2026.11.25.2 (2026-11-25)

CSS-only Boosts are here, with a floating editor for colors, fonts, element zapping, and custom CSS, plus a Profile-wide kill switch in Library. The macOS menu bar now follows Arc's layout, Library adds Media with a lightbox preview, and Archived Tabs can be filtered by Space and date.

## v2026.11.25.1 (2026-11-25)

Space icons and the default Space planet now use filled Ionicons so every Space has the same visual weight in the sidebar. Dark favicons on dark sidebars also invert their lightness to stay readable.

## v2026.11.25 (2026-11-25)

Clicking New Space, New Folder, New Split or New Tab in the sidebar's "+" menu works again. Before, only Return chose a row.

## v2026.11.24.2 (2026-11-24)

Check for Updates shows both the myArc and the Chromium version when you're up to date.

## v2026.11.24.1 (2026-11-24)

The tab context menu follows Arc's, with Mute, Duplicate, Move to, Archive Tab and Archive Tabs Below.

## v2026.11.24 (2026-11-24)

Right-clicking empty sidebar space opens the Space menu, including New Folder. The app is now plain myArc, and it keeps the profile from myArc Nightly.

myArc,
forever yours.

An open-source browser bringing back Arc, with no account required and optional AI.

Download v2026.11.26

How you browse is part of how you work. It should outlast the company behind your browser.

Arc is being sunsetted, and its code was never open, so nobody can keep it going. myArc is open source, so anyone can.

What we hold to

  • Yours to keep

    Your workspace stays on your computer, in local JSON files you own. Export your pins and Favorites as standard Netscape HTML any time.

  • Keep what worked

    If you used Arc, you already know myArc. One-click import brings over your Profiles, Spaces, Favorites, folders and pinned tabs.

  • AI by choice

    AI stays off until you turn it on, with a local model or your own API key. Agents connect over CLI or MCP only when you approve, and stop on your click.

  • Built in the open

    The code is GPL-3.0, and the plans and decisions are public too. If I stop, anyone can pick it up where I left off.

Recent updates v2026.11.26

  • v2026.11.26 (November 26, 2026): Drag the sidebar edge to resize it across Arc's 160 to 500 DIP range, or double-click the edge to reset it. The Boost Editor now uses smoked dark glass, Tree-sitter CSS syntax highlighting, inline autocomplete with Tab and arrow-key cycling, auto-indent, auto-save, a specific element picker, and improved CSS Smart Invert. Little Arc stops oscillating on load, and the footer Profile capsule hover sits flush inside the pill.

The macOS menu bar now follows Arc's layout, Library adds Media with a lightbox preview, and Archived Tabs can be filtered by Space and date.
  • v2026.11.25.1 (November 25, 2026): Space icons and the default Space planet now use filled Ionicons so every Space has the same visual weight in the sidebar. Dark favicons on dark sidebars also invert their lightness to stay readable.
  • v2026.11.25 (November 25, 2026): Clicking New Space, New Folder, New Split or New Tab in the sidebar's "+" menu works again. Before, only Return chose a row.
  • v2026.11.24.2 (November 24, 2026): Check for Updates shows both the myArc and the Chromium version when you're up to date.
  • v2026.11.24.1 (November 24, 2026): The tab context menu follows Arc's, with Mute, Duplicate, Move to, Archive Tab and Archive Tabs Below.
  • v2026.11.24 (November 24, 2026): Right-clicking empty sidebar space opens the Space menu, including New Folder. The app is now plain myArc, and it keeps the profile from myArc Nightly.

What works today

  • Browsing with Chromium extensions and bundled ad and tracker blocking (uBlock Origin Lite)
  • Spaces across multiple isolated Profiles, with custom themes and icons
  • Favorites, pinned tabs and folders, kept across restarts and force quits
  • Two-pane Split View and Peek overlays for links from pinned tabs
  • Little Arc (Cmd+Opt+N) for quick lookups and links from other apps
  • One-click import from Arc (Favorites, Spaces, folders, pins and Profiles)
  • Command bar Cmd+L and Arc's shortcuts, including Cmd+S to hide the sidebar
  • The Library (Downloads, Archived Tabs, Spaces) and Private windows
  • Opt-in CLI (myarc) and MCP (myarc mcp) agent control in an Agent Space
  • Animated welcome tour and signed, notarized in-app updates

Not yet: nested folders, multi-pane Split View, Boosts, workspace export, Mini Player, Windows and Linux.
